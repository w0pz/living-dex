# Pokémon HOME Living Dex & Shiny Tracker

A single-page tracker for a Pokémon HOME living dex and shiny hunts: Dex and form checklists, HOME-style boxes,
a hunt counter with shiny odds, Shiny History, and a Research Lab with encounter locations for X/Y, ORAS and Ultra Sun/Ultra Moon.

Progress is saved in your own browser only (use **Data & Settings → Export / Import progress** to move it between devices).

Data: encounter locations from Serebii; species, forms, sprites and evolution methods from [PokéAPI](https://pokeapi.co).
Independent fan project, not affiliated with Nintendo, Game Freak, Creatures or The Pokémon Company.
